# SCP — Объект 19

Сюжетный кооперативный режим для Garry's Mod: кампания из пяти глав. Глава I — за службу безопасности,
главы II–V — за МОГ Эпсилон-11 «Девятихвостая лиса».

| Глава | Название | Фракция | SCP | Коротко |
|---|---|---|---|---|
| I | Скромник | Охрана | 096 | пост охраны → генератор (гаснет свет) → 3 карты → пульт изоляции → эвакуация |
| II | Не моргай | МОГ | 173 | высадка → камеры наблюдения → 3 предохранителя → клетка → отход |
| III | Лекарство | МОГ | 049 | лаборатория → 3 образца → удержать шлюз 60 с → печь → отход |
| IV | Каскад | МОГ | 096 + 173 + 049 | узел → питание → 3 карты → удержать площадку 75 с → эвакуация за 2:30 |
| V | Омега | МОГ | 049, 096, 173 | командный центр → коды О5 → боеголовка «Альфа» → 95 секунд до поверхности |

## Установка

`dist/scpsite_full.zip` — распаковать в `garrysmod/` сервера: `gamemodes/scpsite` (код) и
`addons/scpsite_content` (контент отдельным аддоном). По частям — `scpsite_gamemode.zip` и `scpsite_content.zip`
(контент можно залить в Workshop и указать `scp_workshop_id <ID>`).

Аддоны из Workshop на сервере и у игроков:
- TFA: `tfa_fml_p90_tac` (охрана), `tfa_ins2_ak12` и `tfa_ins2_usp_match` (МОГ);
- NPC: `npc_shaklin_scp096`, `npc_scp-173_nextbot`, `npc_scp_049`;
- модели охраны `SCP_OZ_Security_1..3` и МОГ `models/scp_mtf_russian/mtf_rus_02/04/05/06/07/08/09.mdl`.

Запуск: `+gamemode scpsite +map <карта>`.

## Расстановка точек — `scp_edit`

`scp_edit` в консоли (суперадмин/хост): меню и сюжет игнорируются, вы на карте с noclip, физганом и тулганом.
**Зажмите C** — панель точек, сгруппированных по главам. У каждой: «Поставить здесь», «Удалить ближайшую»,
«Удалить все», «Посмотреть»/«Телепорт», у катсцен — «Проиграть». Сверху экрана — сколько точек не хватает
в каждой главе. Сохраняется сразу (`data/scpsite/points/<карта>.json`).

**Общие:**

| Точка | Как | Зачем |
|---|---|---|
| Камера главного меню / лобби | по взгляду | фон меню и лобби |
| Спавн отряда — охрана / МОГ | ногами, лицом куда надо (по числу игроков) | старт главы I / глав II–V |
| SCP-096 / SCP-173 / SCP-049 | в их камерах | откуда выходят |
| Точки блуждания SCP | 5–15 штук по уровню | куда SCP переходят, если застряли или долго никого не видят |
| Документ, аптечка, патроны | где лежат | лор, лечение, патроны |
| Источник звука комплекса | у вентиляции, серверов, труб | постоянный гул рядом (5 видов по очереди) |
| Мигающая лампа | под лампой, на полу | живой мерцающий свет и жужжание |

**По главам** (на каждый этап — своя точка; «3+» — несколько, берутся 3 случайные):

| Глава | Точки |
|---|---|
| I | пост охраны · генератор · карта доступа 3+ · пульт изоляции · точка эвакуации · катсцена «Объект-19» |
| II | вход в ЗЛС · щит видеонаблюдения · предохранитель 3+ · пульт клетки · точка эвакуации · катсцена «Не моргай» |
| III | лаборатория · образец 3+ · шлюз дезинфекции (зона) · пульт печи · выход из крыла |
| IV | центральный узел · щит питания · карта доступа 3+ · посадочная площадка (зона) · эвакуация |
| V | командный центр · терминал кодов · боеголовка «Альфа» · выход на поверхность · катсцены «Омега» и финальная |

**Катсцены:** встаньте и посмотрите, откуда должна начаться камера, — «Сюда (по взгляду)»; переместитесь —
ещё точка, и так 3–6 точек по порядку. Камера пролетит по ним плавной кривой. Меньше двух точек — катсцена
пропускается. Проверить — кнопка «Проиграть» или `scp_cutscene_preview <id>`.

Команды: `scp_point <тип> add|remove|clear|tp`, `scp_points`, `scp_story_skip`, `scp_story_stop`, `scp_cutscene <id>`.

## Управление

| Клавиша | Что |
|---|---|
| Q (коротко) | личное дело: снаряжение, документы, статистика |
| Q / E (удерживать) | выглядывать влево / вправо |
| E по товарищу | взаимодействие: перевязать, передать аптечку/магазины, осмотреть, подбодрить |
| Z | команды отряду (круговое меню) |
| G | реплики МОГ Эпсилон-11 (оригинальные голоса SCP:CB) |
| B | рация (весь отряд) |
| X | моргнуть (когда рядом SCP-173) |
| ALT | показать здоровье и патроны |
| ESC | меню паузы и настройки |
| TAB | личный состав; клик по игроку — его громкость |

Настройки (ESC → Настройки): громкость голосового чата, музыки, оповещений и атмосферы; стиль HUD
(«Объект-19», Containment Breach, Secret Laboratory); метки, виньетка, зерно и цветокоррекция; камера и ноги.
