# SCP — Объект 19

Сюжетный кооперативный режим для Garry's Mod. Глава I: **Протокол «Скромник»**. Пересменка на Объекте-19
оборачивается отключением питания и нарушением условий содержания SCP-096.

## Установка

Проще всего — `dist/scpsite_full.zip`: распакуйте в папку `garrysmod/` сервера, получится
`garrysmod/gamemodes/scpsite` (код) и `garrysmod/addons/scpsite_content` (контент отдельным аддоном).

По частям:
1. `dist/scpsite_gamemode.zip` — только код (распаковать в `garrysmod/`).
2. `dist/scpsite_content.zip` — контент (шрифты, иконки, звуки, озвучка, эмблема): в `garrysmod/addons/`
   или залить в Workshop и прописать `scp_workshop_id <ID>` на сервере. Без Workshop клиенты получают его через FastDL.
3. Нужны аддоны на сервере и у клиентов (Workshop-коллекция сервера):
   - оружие **TFA** с `tfa_fml_p90_tac` (и база TFA);
   - NPC **`npc_shaklin_scp096`**;
   - модели охраны `models/arty/codmw2022/sp/mexican federal police/grunts/SCP_OZ_Security_1..3.mdl`.
4. Запуск: `+gamemode scpsite +map <ваша карта>`.

## Первый запуск: расстановка точек — `scp_edit`

Введите в консоли **`scp_edit`** (суперадмин или хост локального сервера). Меню, лобби и сюжет игнорируются:
вы на карте с noclip, физганом и тулганом. **Зажмите C** — откроется панель точек: у каждой точки кнопки
«Поставить здесь», «Удалить ближайшую», «Удалить все» и «Посмотреть»/«Телепорт». Все точки видно маркерами
прямо в мире, сверху экрана написано, чего ещё не хватает для сюжета. Сохраняется сразу в
`data/scpsite/points/<карта>.json`. Повторный `scp_edit` — выход в меню.

| Точка | Сколько | Как ставить | Зачем |
|---|---|---|---|
| Камера главного меню | 1 | встаньте и **посмотрите** туда, куда должна смотреть камера | фон главного меню |
| Камера лобби | 1 | так же, по взгляду (лучше красивый вид, справа будет список отряда, слева/по центру — модель) | фон лобби; если нет — берётся камера меню |
| Спавн отряда | 1+ (лучше по числу игроков) | встаньте на место, повернитесь лицом куда нужно | старт задания |
| SCP-096 | 1 | в камере содержания / в дальнем помещении | появляется на 3-м этапе |
| Цель 1 — пост охраны | 1 | в комнате охраны (радиус ~3 м) | «Доберитесь до поста охраны» |
| Цель 2 — генератор | 1 | на полу, где будет стоять генератор | удерживать E 10 с; на этом этапе гаснет свет |
| Цель 3 — карта доступа | 3+ | в разных углах уровня (берутся 3 случайные) | собрать 3 карты |
| Цель 4 — пульт изоляции | 1 | на полу, где будет пульт | удерживать E 14 с, нужна карта |
| Цель 5 — точка эвакуации | 1 | у выхода/КПП (радиус ~4 м) | финал |
| Документ / Аптечка / Патроны | сколько угодно | там, где лежат предметы | лор, лечение, патроны |

Команды: `scp_point <тип> add|remove|clear|tp`, `scp_points` — список, `scp_story_skip` — пропустить этап,
`scp_story_stop` — прервать задание.

Свет гаснет через `engine.LightStyle(0, …)`: на картах с обычным освещением работает. На картах, где свет
полностью статичный (без lightstyle), останется только эффект экрана.

## Что есть

| Система | Где | Кратко |
|---|---|---|
| Главное меню | `modules/menu/cl_main` | эмблема Фонда над кнопками «Играть» / «Отключиться» слева по центру, сверху — кликабельные обновления (`sh_updates.lua`), терминальная строка, музыка SCP:CB |
| Выбор режима | `modules/menu/cl_select` | затемнение → две панели: одиночная (кикает остальных, `scp_solo_kick 0` — выключить) и мультиплеер |
| Лобби | `modules/menu/cl_lobby`, `modules/lobby` | модель перед вами, стрелки — выбор из трёх, имя сверху — клик для смены; справа отряд, «Пригласить» — список всех игроков, приглашение приходит карточкой «Принять / Отклонить»; голос отряда прямо в лобби; «Играть» — у лидера |
| Сюжет | `modules/story` | 5 этапов, оповещения с озвучкой и субтитрами, метка цели, отключение света, тревога, итоги; погибшие возвращаются на следующем этапе |
| Фразы | `modules/phrases` | персонажи сами говорят: увидел лицо 096, ранен, перезарядка, погиб товарищ, нашёл карту…; **Z** — круговое меню команд отряду |
| HUD | `modules/hud` | виньетка, кровь по краям, здоровье/выносливость/патроны появляются только когда нужны (Alt — показать), имя игрока над головой при взгляде, подсказка E |
| Q — личное дело | `modules/inventory` | оперативник, снаряжение (12 ячеек, документы читаются), статистика службы, текущая задача |
| TAB | `modules/scoreboard` | личный состав объекта: статус (меню/отряд/задание/погиб), отряд, пинг, ПКМ — заглушить |
| Чат | `modules/chat` | свой чат: рядом, `/r` рация, `/w` шёпот, `/y` крик, `/me`, `//` общий; в лобби — отряд; «печатает…» над головой |
| Голос | `modules/voice` | в лобби — отряд; в игре — по расстоянию, **B** — рация всему отряду (щелчки рации), свой значок над говорящими |
| Передвижение | `modules/movement` | шаг 105, бег 215, выносливость, одышка, без распрыжки, ранения замедляют |
| Камера | `modules/camera` | покачивание шагов, крен, дыхание, приземление, толчки от урона; ноги от первого лица (`scp_legs 0` — выключить) |
| Смерть | `modules/death` | камера в глазах тела, сердце останавливается, звук глохнет, темнота → «наблюдение» за живыми |
| Редактор | `modules/editor` | `scp_edit` |

Настройки клиента: `scp_music 0..1`, `scp_camera_bob 0..1.5`, `scp_legs 0/1`, `scp_radio_key`, `scp_phrase_key`.

## Сборка контента и проверка

```
python3 tools/build_content.py --scpcb <клон scpcb> --npm <папка npm-пакетов> --voice <ru-irinia-medium.onnx> [--nyrp-ui <ui-звуки>]
python3 tools/make_archive.py
python3 tools/test/lint.py               # сеть, функции, иконки/звуки/материалы
python3 tools/test/load_test.py --hooks  # загрузка режима в обоих реалмах (pip install lupa)
```
